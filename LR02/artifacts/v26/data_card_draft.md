# Паспорт набора данных (разделы по Gebru и др., 2018)

Сценарий использования: электронный каталог фотоархива (публикация без изменений).

## 1. Motivation (мотивация)

Набор собран для подготовки иллюстраций и медиаматериалов электронного каталога фотоархива. Пользователи — кураторы архива и посетители каталога. Цель — представить материалы в едином каталоге **без изменения оригиналов** и без коммерческого использования; производные работы (кадрирование, коллажи, редактирование) не создаются. Набор носит справочный характер.

## 2. Composition (состав)

* Число объектов: 12; по типам: audio — 4, text — 4, image — 4.
* Распределение лицензий: CC-BY-SA-4.0 — 4, MIT — 3, Apache-2.0 — 3, CC0-1.0 — 1, CC-BY-4.0 — 1.
* Объектов с персональными данными: 0.
* Объектов, для которых лицензия требует указания авторства: 11 (список авторов нужно публиковать вместе с набором).
* Результаты аудита: ошибок — 0, предупреждений — 1.

## 3. Collection Process (процесс сбора)

* Даты получения: 2026-01-01 … 2026-08-21.
* Источники: example.org (вымышленные домены).
* Материалы поступали из внешнего архива; данные о происхождении фиксировались в манифесте. Персональные данные не собирались (в наборе их нет), согласия на обработку персональных данных не требовались.
* У объекта item02 отсутствует дата получения — запрошена у источника, до получения помечена в паспорте как «неизвестна».

## 4. Preprocessing/cleaning/labeling (обработка и разметка)

Объекты **не исключались** — ошибок аудита нет (0 ошибок, 1 предупреждение).
* По предупреждению R8 (item02, отсутствие даты получения): запрошена дата у источника; объект оставлен в наборе с пометкой «дата неизвестна».
* Разметка не выполнялась: набор справочный, метки не требуются.
* Производные работы не создавались: каталог публикует оригиналы без изменений — именно это условие снимает обязательство ShareAlike для 4 объектов с лицензией CC-BY-SA-4.0.

## 5. Uses (использование)

* Предполагаемое: электронный каталог фотоархива (публикация без изменений); коммерческое использование — нет; производные — нет.
* Не подходит для: коммерческого использования; создания производных работ (коллажи, кадрирование, редактирование); распространения под единой лицензией без учёта условий каждого объекта.
* При использовании материалов с CC-BY-SA-4.0 обязательна атрибуция авторов; обязательство ShareAlike **не активируется**, пока не создаются производные.

## 6. Distribution (распространение)

* Публикация набора — предполагается; условия зависят от лицензий объектов (раздел 2).
* Список авторов публикуется вместе с каталогом (11 объектов требуют указания авторства).
* При распространении набора необходимо сохранить атрибуцию и условия лицензий для каждого объекта.

## 7. Maintenance (сопровождение)

* Ответственный — куратор данных архива.
* Запросы правообладателей об удалении или исправлении принимаются по адресу проекта и выполняются с обновлением манифеста и версии набора.
* По объекту item02 ведётся отдельный трекер: до получения даты от источника запись помечена как «дата неизвестна»; при появлении даты — обновляется манифест и паспорт.
* При изменении сценария использования (например, добавление коммерческого использования или производных) — обязательный повторный аудит.
