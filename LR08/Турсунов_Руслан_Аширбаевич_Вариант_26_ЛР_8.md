## 1. Цель и постановка задачи

**Цель работы.** Построить вариационный автокодировщик на синтетических сценах, получить из него новые изображения (сэмплы из априорного распределения) и промежуточные сцены (интерполяция между двумя изображениями) и выяснить экспериментом, как на качество реконструкции, интерполяции и сэмплов влияют вес β, размер латентного вектора, способ интерполяции и разброс сэмплов.

**Набор сцен (вариант 26).** 5 — `two_discs`: янтарный и розовый диски в разных половинах кадра. **4 фактора:** положения обоих дисков.

**Серия seed.** 101…105.

**Гипотеза (записана до запуска).**
- **Реконструкция** — ухудшится на 0.5–1.5 дБ (цена KL-члена).

- **Сэмплы** — резко вырастут на 8–10 дБ (главный эффект).

**Практический допуск (задан до эксперимента).**
- Реконструкция: ±1.0 дБ
- Интерполяция: ±1.0 дБ

**Критерий успеха.** Гипотеза и допуск записаны до запуска; изменён ровно один фактор; результаты по 5 seed; вывод отделяет наблюдение от объяснения; диагностика (разброс μ, активные оси) приведена.

**R² = −0.073** — **на грани** допуска ±0.05. При допуске ±0.1 — был бы «в допуске». Это **важная оговорка**: R² **снизился**, но **насколько это критично** — зависит от того, насколько важна линейная интерпретируемость для задачи. Если важна — ухудшение; если нет — нейтрально.

**Реконструкция −0.799** — **на грани** ±1.0. При допуске ±0.5 — было бы «ухудшение». Но при ±1.0 — «в допуске».

**Сэмплы +8.443** — **далеко** за допуском ±1.0. Устойчивый вывод.

**Ошибка 1: VAE без разогрева KL-члена.** По журналу демо: seed 102 схлопывается при обучении без warmup (PSNR 17.2 — на уровне эталона «средняя картинка»). С warmup 10 эпох — все seed дают 25.6–26.9 дБ. В нашем запуске warmup=10 (по умолчанию), поэтому схлопывания **нет**.

**Ошибка 2: сэмплы из N(0, I) у обычного автокодировщика.** Строка 1 `comparison.png` — сэмплы AE выглядят как «пятна», PSNR 13 дБ. Причина: разброс μ у AE большой (5.67–6.97), сэмплы вне области обучения. Исправление: использовать VAE (KL-член стягивает μ к N(0, I)).

### 6.5. Угрозы валидности

## 7. Вывод

**Цель достигнута.** Построен VAE, получены сэмплы из N(0, I), интерполированы промежуточные сцены, проверено влияние модели (AE → VAE) по серии из 5 seed.

**Основные результаты:**

1. **Сэмплы:** **+8.443 дБ** — **главный эффект**. VAE делает сэмплы из N(0, I) пригодными (PSNR с 12.88 до 21.32). Значимо по 2s (28.80) и по допуску (+8.4 > 1.0).
2. **Реконструкция:** −0.799 дБ — **в допуске**. Незначимо по 2s (1.62 < 2). Цена KL-члена.
3. **Интерполяция:** −0.084 дБ — **нейтрально**. Контрольная метрика для фактора `ae_to_vae`.
4. **R²:** −0.073 — **за допуском**, значимо по 2s (2.45). VAE **хуже** линейно интерпретируется — компромисс: генеративность vs интерпретируемость.
5. **Диагностика:** у AE разброс μ большой (5.67–6.97), у VAE — близко к N(0, I) (0.6–1.04). Активных осей у VAE — **8** (все).
6. **Визуально:** строка 1 (AE) — «пятна», строка 2 (VAE) — чёткие диски. Главное подтверждение: VAE делает сэмплы пригодными.

**Ключевое объяснение.** У **AE** латентный вектор **не распределён** как N(0, I) — разброс большой, сэмплы из N(0, I) попадают **вне области обучения** → мусор. У **VAE** KL-член **стягивает** распределение к N(0, I) → сэмплы **пригодны**. Это **главный практический вывод**: для порождающего использования нужен VAE. Цена — **снижение R²** (линейной интерпретируемости) и **небольшое ухудшение реконструкции**.

**Практический вывод.** Для порождающего использования (сэмплирование) — **VAE**. Для точной реконструкции — **AE**. Интерполяция работает в **обоих**. R² — компромисс: VAE улучшает генеративность, но снижает линейную интерпретируемость.

**Воспроизводимость.** Результат совпадает с эталоном преподавателя в пределах **0.1 дБ**. Значимость (2s) совпала полностью.

```python
# Проверка settings
a, b = V.settings("ae_to_vae")

# Сводка варианта
result = V.variant_summary(26)

# Диагностика
Xte = L.dataset(kind)[1]
for name, beta in (("AE, beta=0", 0.0), ("VAE, beta=1", 1.0)):
    model = V.get_model(kind, dict(V.BASE, beta=beta), 101)
    with torch.no_grad():
        mu, lv = model.encode_dist(Xte)
        kl_axis = (-0.5 * (1 + lv - mu ** 2 - lv.exp())).mean(0)
    m = V.metrics(model, kind, "lin", 1.0, 101)
    active = int((kl_axis > 0.05).sum()) if beta > 0 else "-"
    print(f"{name}: разброс mu {mu.std(0).cpu().numpy().round(2)}; активных осей {active}")
```
