## ЛР 3. Подготовка изображений и визуализация в Engee

Вариант 26 — сцена «шахматная структура» (серые клетки 8×8 пикселей), воздействие «уменьшение в 2 раза и возврат к исходному размеру» (`imresize`). ## ЛР 4. Исследование операций обработки изображений в Engee

Вариант 26 — сцена «низкий контраст» (диск 0,55 на фоне 0,35–0,50), операция «фильтр Гаусса σ = 1». Работа в Engee (Julia 1.12.4). Подготовлена синтетическая сцена 128×128 с шумом σn = 0,03 и чистый эталон; PSNR зашумлённой сцены относительно эталона составил 30,46 дБ — точно совпал с теоретической оценкой −20·lg(0,03) ≈ 30,46 дБ. Фильтр Гаусса σ = 1 улучшил PSNR на 8,72 дБ (30,46 → 39,18 дБ) относительно эталона, при этом энергия границ упала на 61 %, контраст — на 11,6 %. По практическому допуску (±1 дБ по ΔPSNR) операция классифицирована как **полезная** для этой сцены. Проверена целостность библиотек: SHA-256 `lab04_lib.jl` (`094cecea...`) и `lab03_lib.jl` (`cd162264...`) совпадают с эталонами МУ.

Материалы лежат в папке [`LR04/`](LR04/): исходный код (`src/LR04_26.ngscript`, `src/lab04_lib.jl`), артефакты (`artifacts/noisy.png`, `result.png`, `clean.png`), журнал эксперимента (`journal.md`), отчёт.

Вариант 26 — бриф «обложка электронного музыкального релиза» (металл с радужными бликами, макросъёмка), условие «смена seed на единицу». Работа в **Google Colab** с GPU Tesla T4: запущена открытая модель `stabilityai/sd-turbo` (ревизия `b261bac6fd2cf515557d5d0707481eafa0485ec2`) по закреплённой ревизии, получено изображение и сохранён манифест условий запуска (`result.png`, `manifest.json`). Сравнены изображения A (seed 1026) и B (seed 1027): SHA-256 различаются, PSNR = 12.63 дБ, `pixel_equal = False`, вердикт `different` — гипотеза подтверждена. Воспроизведена намеренная ошибка (общий `Generator` на два запуска): первый совпал с эталоном, второй нет, PSNR = 11.9 дБ. Проверен детерминизм: отдельная генерация B дала SHA, совпадающий с `sha_b` из `variant_summary(26)`. Лицензия модели — Stability AI Community License (учебное, некоммерческое использование).

## ЛР 6. Исследование параметров text-to-image генерации

Вариант 26 — бриф «обложка электронного музыкального релиза» (металл с радужными бликами, макросъёмка), фактор «размер кадра: 512 → 384». Работа в **Google Colab** с GPU Tesla T4: запущены модель `stabilityai/sd-turbo` (та же ревизия, что в ЛР 5) и CLIP `openai/clip-vit-base-patch32` для оценки сходства. Сравнены два режима (A — 512, B — 384) на серии из 5 seed (101…105) по четырём метрикам: CLIP, энергия границ, контраст, время. Результат: CLIP **+2.10** (вышел за допуск ±1.0, но по критерию 2s незначимо — |Δ|/s = 1.97); энергия границ **−11.5 %** (метрика размер-зависима, ожидаемое падение); контраст **+3.4 %** (в допуске); время **−33.7 %** (существенное ускорение). Вывод: уменьшенный кадр **пригоден для черновиков** — содержание сохранено, ускорение на треть, детализация ниже. Воспроизведена намеренная ошибка (guidance 1.0 не отличается от 0.0, CFG активируется только при > 1). SHA-256 обеих библиотек (`lab05_lib.py`, `lab06_lib.py`) совпадают с эталонами МУ.

Материалы лежат в папке [`LR06/`](LR06/): исходный код (`src/lab05_lib.py`, `lab06_lib.py`, демо-скрипты), артефакты (`artifacts/comparison.png`, `LR06.ipynb`), журнал эксперимента (`journal.md`), отчёт.
