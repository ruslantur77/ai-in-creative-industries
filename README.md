## **ЛР 1. Подготовка рабочей среды и паспорт воспроизводимого AI-эксперимента.** 
Вариант 26 — контекст «зернистая плёнка (постобработка)», фактор «число октав +1». Подготовлена изолированная среда Python (`.venv`), составлен паспорт эксперимента, выполнен протокол воспроизводимости, рассчитаны четыре метрики (mean, contrast, edge, entropy) по n = 5 seed для базы и фактора, проверена гипотеза по критерию |Δ| > 2·s_base. Дополнительно подготовлена среда Engee (Часть Б) — зафиксированы версии платформы и Julia, создан скрипт `LR01_environment.ngscript`.

Материалы ЛР 1 лежат в папке [`LR01/`](LR01/): журнал эксперимента (`journal.md`), паспорт (`passport.md`), исходный код (`src/`), артефакты (`artifacts/v26/`). Протокол воспроизводимости выполнен полностью (EQ_1_2 = true, EQ_1_4 = true, EQ_1_3 = false, EQ_2_4 = true); влияние фактора обнаружено для трёх метрик из четырёх (contrast, edge, entropy), гипотеза опровергнута по направлению — предсказывался рост, фактически метрики упали.
